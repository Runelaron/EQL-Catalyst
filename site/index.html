Start your journey

Installed like a classic
Windows app.

  1. Download and verify.

    Get the installer below and compare its SHA-256 with the release checksums.

  2. Choose your installation.

    “Install for me” is recommended. All-users installation is optional and requests elevation; the app runs unelevated.

  3. Choose a character.

    Select the game folder and character on first launch, or leave the folder blank to explore offline. Your last profile is remembered.

  4. Bring in your evidence.

    Enable /log on and make a complete /outputfile inventory capture. Automatic sync is optional and off until enabled and verified.

A few things to know.

What is still being tested?

This is a beta. Physical-monitor DPI and live-game input/capture acceptance remain separate. Disputed focus benefits, some pet mechanics and incomplete roster/effect coverage stay explicitly qualified. Cross-session Class Loadout comparison is in development.

Can I update or uninstall safely?

Close Catalyst and resolve unsaved Theorycraft edits before updating. Setup refuses locked files rather than force-closing the app. Profiles are stored outside the application folder and survive uninstall. See the installation guide.

Is this an official EverQuest application?

No. EQL Catalyst is an independent community companion and is not endorsed by Daybreak, Darkpaw or Game Jawn. EverQuest and referenced characters/trademarks belong to their owners.

Where can I see the source and report a problem?

The maintained source is GPL-3.0-only on GitHub. Wiki content, fonts and dependencies retain their own licenses. Open an issue with reproduction steps and redacted screenshots—never private profiles or raw captures.
