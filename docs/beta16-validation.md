# Beta 1.6 validation

Source version: **1.6.0-beta.1**, label **Beta 1.6**. Exact public package hashes, source commit, hosted Windows results, SBOM and signing evidence accompany the release.

- Complete core suite: **1,661/1,661**, 7.25 seconds. Includes new template, vendor/reward evidence, Starts In, named-NPC qualification and alias regressions, plus retained rank/effect/draft/research tests.
- Native shared-toolbar regression: **110 assertions**. Includes real routed Thumb capture/release ordering, reversal, Escape, capture loss, locks, persistence, first-open-before-Loaded, animation interruption, dirty-work cancellation, monitor/DPI placement projections and independent saved dimensions.
- New Beta 1.6 native review: **44 assertions**, 26.55 seconds. Includes routed physical header drag with native joined-edge checks on four reversals, pointer/grip/Close/sprocket bounds, Current/historical session selection, shared zone/named/date/damage/healing/export selection, independent overlays, stable disclosure bounds at 1000/640 DIP, Fire/Undead independence, restart-store reads, high-DPI decoding and rapid stale-result rejection.
- Gallery: 55 metadata-defined concepts, seven review-only revisions, four selected defaults, three Settings alternatives and 41 archived concepts. Native DPS controls cover 13/14/16/20/24/32/64 DIP across Coldain/Sunstrider/Shadowman, grayscale and silhouettes. No raw personal capture is used.
- Content crawl is cached, rate-limited and revision-aware. Generic Namedmobpage formatting was found on ordinary mobs and is explicitly rejected as sufficient named-status proof. Unfilled numeric/slot/class examples are suppressed while supported acquisition relationships remain. Full coverage/dispositions are bundled.

The earlier missed resize regression simulated capture loss in the wrong order. WPF Thumb normally releases capture before DragCompleted; the retained lifecycle regression now commits that normal release and separately tests genuine loss and cancellation.

Timing outliers remain in local reports. One initial synthetic apphost lacked DOTNET_ROOT and never loaded the CLR; it was stopped only after verifying its diagnostic path and arguments. An early UI probe reused a hidden toolbar-owned Lab and failed its visibility precondition; the final run creates a fresh Lab. No production process or combat ingestion was used for these checks. Animation reversal sampled 46.57 ms at 0.759 progress; this is recorded evidence, not a universal frame-rate guarantee.

Native current-monitor movement and focused normal/minimum-width tests are complete. Physical transitions across differently scaled monitors, broad window theme/DPI matrices, fresh-OS and Windows policy/SmartScreen acceptance, and live-game acceptance remain separately scoped. No Sandbox or Store submission is used. Security findings and package-specific installer/updater checks are reported with the final release assets rather than borrowed from older hashes.
