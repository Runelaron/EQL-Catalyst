# Beta 1.8

Beta 1.8 refreshes the offline item, quest and spell references and includes the
desktop improvements completed since Beta 1.7: Overview item previews and
financial evidence, conservative outgoing-damage peaks, Bard rotation comparison,
charged-click Exaltation filtering and pressed reward names.

The fresh item index contains 19,117 titles, including 63 newly indexed titles
and 61 changed existing bundled definitions. There are 7,001 bundled item
definitions and 2,015 spell references. Indexed titles are not all complete
equipment definitions. Missing acquisition metadata remains explicit.

Castle access now describes normal and non-raid personal Plane of Hate instances.
The blessing hand-in's documented level restriction and additional Everling
coordinates are included. Halloween acquisition offers are explicitly historical after November 3; owned copies are preserved. Reviewed checklist identities remain stable. Official
October 27/29 and November 3/4 changes are retained with sources; undocumented
coefficients do not become calculation formulas.

EQL Quest Display is locally generated font software reconstructed from supplied
reference lettering. Contributors' rights are licensed under SIL OFL 1.1; the
notice distinguishes third-party rights and makes no endorsement claim. Catalyst
branding uses its separate Classic font treatment. Reward names retain live,
raised/inset display lettering.

Windows installer and portable packages remain self-contained and bundle the security-fixed .NET 10.0.14 runtime. Automatic checks
and authenticated read-only LAN sharing remain opt-in. Public builds disable
private research. Existing profiles, custom weights, gear, progress and evidence
are preserved. Windows binaries remain unsigned; signed update metadata is a
separate verification mechanism.

## Linux status

A native Avalonia frontend and shared desktop orchestration are being validated.
It is not the Windows program wrapped in Wine. Linux packages are not advertised
as supported until desktop parity and platform acceptance pass. Ubuntu 24.04 x64
and Steam Deck Desktop Mode are the targets; Gaming Mode overlays are experimental.
Windows may release first. See [Linux development](linux-desktop.md).
