# Pet workspace validation

This is a focused local iteration. Published Beta 1.4, installers, Store submission and GitHub publication are unchanged. No WSL or Sandbox operations were performed.

## Evidence

- 16 focused workspace tests cover isolated drafts, complete Undo, commit baselines, concurrent source changes, followed detection, independent plans, fixed hands, replacement, swapping, removal, retained conflicts, high recorded ranks, zone aliases and unchanged quest state.
- 231 Pet regressions and 42 Progress regressions pass. The Pet set includes workspace, research, contribution, rank, effect-policy and summon-context checks. An old catalog-count assertion was updated from 86 to 88 to include the two previously added Monster summons; no summon formula changed.
- The synthetic WPF review exercises the toolbar, clean/dirty buttons, Current and planned saves, Save/Discard/Cancel, conflict review, typed rank validation, slot sizing, routed drop operations, comparison stability, mode switching and independent searches. Run receipts identify the exact app/core hashes and private-research gate.
- Focus and accessibility-toggle tests cover both sides of the Filter wrap threshold with identical pre/post bounds and a 28-DIP height. The shared disclosure reserves its border in every state. A preliminary native pointer run passed at normal widths; attempts at the tighter threshold were disrupted by desktop cursor/foreground changes. Those attempts are retained as a validation limitation rather than represented as passing native pointer checks. Deterministic wrap checks use WPF UI Automation.
- Native `PrintWindow` captures include the actual dialog frame at the machine's current 300% scale: client top offset zero, no white caption/glass band. The compact client is 460 × 360 DIP; the native bounds are 1380 × 1080 pixels. This checks the HWND surface in addition to client-content renders. Expanded/collapsed height and unchanged width are asserted. Broad theme/DPI matrices remain deferred.

## Repairs found during implementation

The original Filter face gained border space on focus, allowing a field to wrap between pointer transitions. Its new toggle reserves that space. Acquisition-zone text matching initially repeated regular-expression construction; the index now builds one reusable pattern and caches its documented relationships.

The slot editor compares editable item/rank/effect values, rather than timestamps or metadata bookkeeping. Opening or canceling it does not mutate the build. A preselected new item differs from an empty position and can be saved; returning to the original values clears dirty state. Legacy ranks and conflicting retained configurations stay available for review.

Comparison polling fingerprints the selected equipment/context, applicable weights, relevant item facts, measurement history and preferences. It excludes edit counters, timestamps and acquisition-source refreshes. Equivalent work coalesces, completed cards remain visible, and Updating has a 150-ms delay. Obsolete requests cannot replace the current result. The review retains idle results through timestamp/history-only changes and refreshes real rank edits.

## Delivery checks

The final local and public configurations are reviewed separately to verify that Pet data remains gated. Targeted source, changed-payload and preview privacy receipts are kept outside the distributable. App, profile and private research backups are hash-verified before replacing the local running copy. Startup verification compares saved profiles, inventory evidence, private research, combat/observation tables and independent log checkpoints against the shutdown backup. No ingestion replay or checkpoint rewind is part of this change.

Personal evidence and runtime receipts remain outside bundled catalogs, public fixtures and published artifacts. The local update retains the existing version label and update helpers.
