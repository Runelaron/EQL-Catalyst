# Appearance, shortcuts and panel spacing

Appearance saves per character and updates open windows immediately. Damage emblem and Tab style are alphabetical visual dropdowns; their larger examples show the selected choice. Damage emblem follows Clean/Vibrant. Meter style keeps Minimal, Frost and Luminous and shows its example directly below. Shadowman uses neutral near-black surfaces while retaining semantic combat colors and transparency.

Combat settings offer 6, 8, 10 and 12-second idle cutoffs, plus Custom. Custom reveals its numeric field; supported values are whole seconds from 2 through 120. Existing nonpreset values stay Custom. Resume is 0 to disable, or at least the cutoff and no more than 300 seconds. Save changes validates both without changing encounter arithmetic.

Advanced keeps Display setup and Hotkeys visible. For each overlay shortcut choose Change, press a combination, then Save changes. Escape cancels recording. Reset restores that action's default after saving. Use a modifier with letters, numbers or navigation keys, or a function key except Windows-reserved F12. Duplicate actions and unavailable Windows registrations are rejected; working bindings stay registered when a replacement fails. Capture shortcuts remain separately configured and verified in Native controls.

Inspector borders now sit beside the existing five-DIP splitter gutter, without a second horizontal outer inset. Card padding, floating labels, handles, cascading resizing and saved widths are retained.
